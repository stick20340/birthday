🔐 비공개 생일 페이지 편집기

편지와 사진을 암호화해서 한 파일로 만듭니다.
중요: 여기서 입력한 비밀번호는 파일 안에 저장되지 않습니다. 잊어버리면 암호화된 편지를 복구할 수 없어요. 기존 편지를 수정할 때는 비밀번호를 입력한 뒤 현재 편지 불러오기를 누르면 됩니다. 완성된 encrypted-data-gift-XXXX.json 파일만 GitHub에 올리면 되고, GitHub에는 편지와 사진이 읽을 수 없는 암호문으로 저장됩니다.

생일 페이지 관리

모든 사람은 각자 고유한 페이지 ID를 사용합니다. 새 사람을 만들 때마다 새 사람용 페이지 만들기를 누르면 기존 편지와 완전히 분리됩니다.

사이트 비밀번호

임시저장 준비됨

짧고 흔한 비밀번호보다 여러 단어와 숫자를 섞은 비밀번호가 좋아요. 비밀번호는 디스코드 DM 등으로 따로 전달하세요. 사람마다 같은 비밀번호를 써도 충돌하진 않지만, 서로 다르게 정하는 편이 더 안전합니다.
